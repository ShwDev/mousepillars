# mousePillars

Mod de Fabric para Minecraft 26.3. Implementa un pilar que convierte en ratón (o cualquier cosa jjjj) a quien entre en su área
(hitbox reducida, sin inventario ni hotbar). Cada pilar tiene un boton vinculado para prender o apagar el pilar, funciona con ID.

Inspirado en el Palacio de Shido de Persona 5.

## Uso rápido

- **Creativo**, clic derecho en el pilar: GUI con Estado ON/OFF, Rango (N x N) e ID de vinculación.
- **Creativo**, clic derecho en el botón: GUI con la ID de vinculación. (Shift + mano vacía = alternar sin cambiar de modo.)
- **Supervivencia**, clic derecho en el botón: alterna todos los pilares cargados con la misma ID.
